# Revenue Leak Audit

Skills-only development plugin, version 0.1.1, by AI Growth Studio.

Diagnose gaps across the home service lead-to-job journey and produce a practical improvement blueprint.

## Try it

Audit where leads fall through the cracks in my home service business.

The skill creates company-branded `.md` and `.html` reports and an internal implementation blueprint. It runs with the host’s available file and read-only browsing tools; report helpers use Python standard library and no external network. No customer sending or live account changes. See `PRIVACY.md`.
