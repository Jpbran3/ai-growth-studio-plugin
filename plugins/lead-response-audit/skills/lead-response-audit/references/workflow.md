# Lead Response Audit: diagnosis

Journey: received inquiry → assigned owner → appropriate first response → two-way contact → qualified next step.

Distinguish notification delivery, owner assignment, first attempted response, meaningful two-way contact and a qualified next step. A fast automated acknowledgement is not a human response or confirmed contact. Deduplicate calls/forms/emails concerning one opportunity; retain event timestamps separately. Check channel, staffed hours, local timezone, priority, assignment and reassignment. A longer overnight interval is not automatically a breached staffed-hours promise. Use the business's established escalation for urgent requests; do not invent hazard instructions or arrival guarantees.

Likely causes include inaccessible notifications, unclear ownership, stale routing, after-hours coverage, unsuitable channels and incomplete information. Trace one representative inquiry before recommending bots or a new CRM. A healthy response process is a valid finding. Public claims about response speed do not establish actual performance.

Separate symptom, cause hypothesis, alternative explanation and validation step. Labels and limitations belong with findings. Use anonymized examples/aggregates where possible; no credentials or unnecessary customer information. A brief focused report is preferable to repeating unrelated funnel questions.
