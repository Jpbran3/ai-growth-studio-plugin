# Practical process design

Deliver a metric dictionary: decision/use, numerator, denominator, unit, stage-entry/exit, exclusions, date basis, cohort/cutoff, source/status, owner and refresh/reconciliation rule. Add a minimal anonymized log or export specification, duplicate handling, missing-data check, source precedence for conflicts, ownership and review cadence as suggestions. Use the existing stack where sufficient; do not default to a warehouse/CRM migration. No tracking pixels, account connections, data uploads or live dashboard changes are executed.

Suggested assignments, timing and targets are proposals until the owner agrees. Give a manual alternative and failure path for every automation recommendation. Confirm inputs, accountable role and exception handling before any later implementation.
