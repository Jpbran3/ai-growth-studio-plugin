# Practical process design

Specify completion trigger, suggested responsible role, owner-approved neutral invitation, preference/exclusion check, unresolved-issue owner and referral acknowledgement/qualification path. Draft honest requests using only an actual owner-provided review link, otherwise state that it is needed. Avoid made-up star ratings or scripts that pressure removal of negative reviews. No posting, account edits, outreach, public replies or rewards are executed. A service complaint should route to resolution while preserving a neutral invitation approach.

Suggested assignments, timing and targets are proposals until the owner agrees. Give a manual alternative and failure path for every automation recommendation. Confirm inputs, accountable role and exception handling before any later implementation.
