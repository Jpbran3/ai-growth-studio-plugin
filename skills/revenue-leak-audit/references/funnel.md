# Two-layer diagnostic method

Layer 1: locate a transition where eligible leads fail to progress. Layer 2: identify the supported cause; list alternatives and a discriminating check if uncertain. Only then select an intervention.

## Map the actual business

Emergency/repair: inquiry → qualified contact → booked visit → completed visit → authorized/completed paid job. A separate estimate visit may not exist.

Project trades: inquiry → qualified contact → estimate booked → estimate completed → quote delivered → accepted job → scheduled/completed job. Quote delivered is not estimate completed, and accepted value is not collected revenue.

Recurring services: inquiry → qualified contact → first visit booked → first visit completed → active recurring customer. Retention is a later separate cohort, not another stage to subtract from this month's leads.

Mixed work: keep separate paths for service and projects when economics/processes differ. Use branches for direct bookings; do not force every job through an estimate.

## Denominators and time

Choose one period and one cohort. For each stage record count, source, unit, period and definition. Identify in-progress leads and maturation lag. Stage drop-off = eligible entrants minus progressed minus legitimately pending, with exits/reasons stated. A 50% estimate close rate is accepted jobs divided by completed/delivered eligible estimates from the same matured cohort, not jobs sold this month divided by estimates created this month.

Phone logs count call attempts, not necessarily unique new prospects. Advertising dashboards may count repeated conversion events, booked appointments or platform-attributed actions. Do not equate these without reconciliation. Deduplicate by a suitable anonymized identifier if uploaded data supports it, preserving uncertain matches as uncertain. No file processing is needed without data.

## Finding contract

Every finding contains: zone/stage → observed symptom and evidence → count/range if supported → source status → cause supported or hypothesized → alternative explanation → recommended fix → how to validate → confidence → priority with rationale. Label a gap “suspected” if there is no measured drop-off. No universal close-rate or response-time benchmark is built in.

## Attribution

Acquisition quality and handling are different diagnoses. Geographic mismatch, spam, irrelevant services or insufficient capacity may explain low job yield. Spend alone proves none of them. Attribution should use source-to-job reconciliation where possible, and acknowledge multi-touch attribution and missing sources. Neither all advertising spend nor every unclosed lead is recoverable revenue.
