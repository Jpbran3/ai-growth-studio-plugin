# Measurement contract

Response intervals need received and response timestamps with timezone and a defined clock (elapsed or staffed hours). Define first substantive response consistently; report median/tail only from available timestamps, not owner adjectives. Exclude test/spam records explicitly, preserve unknown timestamps and pending inquiries, and separate attempted contact from reached contact. Never infer unique lost customers from unanswered notifications. Financial modeling is optional only if requested, using eligible unresolved unique opportunities and explicit incremental downstream probabilities and delivery capacity.

If an optional financial scenario is both requested and appropriate, use explicit labeled inputs and matching horizons/cohorts. Incremental completed work requires a baseline and proposed outcome on the same eligible pool, relevant downstream stages and available additional delivery capacity. Multiply only supported incremental completed jobs by comparable realized revenue per completed job. For renewals, distinguish new accepted contract value from completed revenue. Reject negative/nonfinite inputs and rates outside 0–1; a proposed rate below baseline is not a positive opportunity. Unknown capacity leaves the cap unresolved and reduces projection confidence. No defaults or guaranteed recovery. Verify arithmetic using available calculation tools and expose formulas; never claim a helper ran when it did not. No addition of overlapping pools from portfolio audits.
