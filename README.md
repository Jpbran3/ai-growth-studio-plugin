# AI Growth Studio

Development version **0.5.1**: ten self-contained skills for home service businesses. Each complete or preliminary report saves editable Markdown and a matching styled HTML companion. Explicit owner branding wins, then verified website styles; otherwise plumbing blue #1565C0, HVAC light blue #62B5E5, med-spa-style deep green #006039 or other/mixed-trade soft blue #7BAFD4. Medical auditing is not included by palette support.

## Included skills

- **Revenue Leak Audit** (`$revenue-leak-audit`)
- **Missed Call Revenue Calculator** (`$missed-call-revenue-calculator`)
- **Unsold Estimate Audit** (`$unsold-estimate-follow-up-audit`)
- **Booking & Handoff Audit** (`$booking-handoff-audit`)
- **Lead Response Audit** (`$lead-response-audit`)
- **Customer Reactivation Audit** (`$customer-reactivation-audit`)
- **Maintenance Renewal Audit** (`$maintenance-renewal-audit`)
- **Review & Referral Audit** (`$review-referral-audit`)
- **Capacity & Scheduling Audit** (`$capacity-scheduling-audit`)
- **Conversion Measurement Audit** (`$conversion-measurement-audit`)

Skills diagnose their distinct requested scope, label evidence/assumptions, avoid unsupported revenue and provide an internal blueprint. They use supplied information and permitted read-only website inspection. They do not connect live CRM/phone/accounts, send customer messages, change calendars, monitor customers or execute fixes. Optional implementation disclosure comes after useful complete findings; preliminary reports and declined promotion omit it.

## Install and try

The existing repository marketplace contains `ai-growth-studio`. Local development installation is verified separately from what is currently published on GitHub. Start a fresh chat after updating and invoke the desired `$skill-name`.
